# Offer 引力

> 让好工作，主动靠近你。

## 产品定位

面向中国全部行业求职者的 AI 求职分析、投递决策与复盘工具：帮助用户分析个人情况、选择行业和岗位、判断哪些职位值得投、准备针对性材料，并根据真实回复结果持续优化求职策略。

产品不保存招聘平台账号密码，不绕过验证码或风控，不以爬虫、模拟用户或未经许可的自动投递作为核心能力。

## 核心价值

- 少做无效海投，把时间集中到更有机会的岗位；
- 解释职位匹配与缺口，而不只给一个模糊分数；
- 根据岗位生成真实、可核验的简历修改建议和开场话术；
- 针对目标岗位和 JD 重组简历证据、调整表达并列出缺失信息，不虚构经历；
- 通过 12 个工作情境分析协作、秩序、探索、节奏、细节和自主偏好，并与真实经历一起判断适合的岗位与工作环境；
- 通过 20 个情境生成 MBTI 职业偏好画像，提供四维倾向、优势、岗位族群和适合环境；MBTI 只作为探索参考，不作为岗位淘汰依据；
- 根据用户自由填写的职业、行业、技能、城市和性格画像动态生成监控词，不依赖预设职业目录；
- 汇总用户分享或获授权渠道中的招聘信息，自动判断适合度，并对高匹配机会发出提醒；
- 记录投递、回复和面试结果，用数据找出问题发生在哪一环；
- 用户始终审核并决定最终提交的内容。

## 目标用户

面向全部合法行业和岗位的求职者。行业与岗位可以自由填写；商业验证仍可从更容易触达的细分人群开始，但产品能力不绑定设计行业。

## 商业原则

- 卖“提高有效回复率的决策系统”，不卖“无限自动海投”；
- 首版先验证用户是否愿意为结果诊断和节省时间付费；
- 不承诺 Offer，不伪造经历，不代替用户作出重要求职决定；
- 简历和投递记录属于高敏感度用户数据，默认最少收集、可导出、可删除。

## 当前阶段

可运行商业化 MVP：本地模式可直接体验；已具备账号、云同步、套餐权益、支付适配、公开岗位采集、后台同步、通知基础和结果复盘接口，正式上线仍需配置第三方密钥与生产基础设施。

- 59 元／14 天：合理使用范围内 100 次岗位分析、每日机会雷达、12 次针对性简历、14 天策略和 2 次结果复盘；
- 129 元／30 天：300 次岗位分析、即时机会雷达、30 次针对性简历和 4 次结果复盘；
- 299 元／30 天：500 次岗位分析、即时雷达、50 次针对性简历、6 次复盘和人工策略复核；
- 已实现服务端套餐权益和通用支付适配；配置微信支付／支付宝服务端和安全回调后才能真实收费。

## 产品信息架构

左侧商业化功能导航依次包含：求职总览、AI 求职分析、性格与工作环境、MBTI 职业性格、全职业机会雷达、BOSS 智能投递、AI 改写简历、岗位判断、投递中心、14 天求职方案、个人档案和数据设置。每项均说明能解决的问题，并展示当前套餐和剩余额度。

## 全职业机会雷达

- 适用于用户自由填写的任意合法职业，不把职业范围写死在前端；
- 根据目标岗位、行业、技能、城市和性格分析自动建议监控关键词；
- 当前可接收小红书、抖音、招聘平台、公司官网等来源的用户分享链接或粘贴内容，并立即给出匹配分、理由、风险和提醒；
- 已支持企业公开招聘页 `JobPosting`、Greenhouse 和 Lever 公开职位源，自动做字段标准化、过期过滤、去重与风险提示；
- 登录后可保存公开招聘源，服务端每 30 分钟执行后台同步并生成高匹配站内通知；
- 已具备 Service Worker 与 Web Push 接收基础；真正的离线外部推送仍需配置 VAPID 发送服务或微信通知；
- 不以绕过登录、反爬、验证码或平台访问限制的方式抓取内容。

## 与 BOSS 直聘的联动边界

- 未获得 BOSS 直聘书面许可或正式开放接口前，不使用第三方工具登录账号、浏览或抓取职位、收发简历，也不绕过平台流程；
- 当前采用“用户手动粘贴 JD → 本产品分析与准备材料 → 用户返回官方页面确认投递”的合规闭环；
- 如果未来获得官方合作，优先采用授权跳转、职位链接导入、OAuth／开放接口或联合活动，不模拟用户操作；
- 获客侧优先经营独立落地页、免费 10 岗位工具、可分享的性格工作画像、校园／社群合作和内容 SEO，再与 BOSS 直聘洽谈正式品牌或业务合作。

## BOSS 智能投递

- 对机会雷达中由用户主动导入的 BOSS 岗位自动筛选，不自动登录或爬取 BOSS 职位；
- 支持最低匹配分、每日上限、排除关键词和简历版本规则；
- 自动排除低匹配、过期、招聘主体不明确、疑似收费及命中用户排除项的岗位；
- 为每个岗位准备真实简历版本和基于用户经历的招呼语，形成待投递队列；
- 未配置官方接口时，只允许打开 `zhipin.com` 官方链接，由用户完成最后确认并记录结果；
- 获得 BOSS 书面授权后，配置官方 API 地址和令牌，同一菜单会显示“官方接口模式”，但每次提交仍要求求职者明确授权；
- 不保存 BOSS 账号密码，不模拟点击，不绕过验证码、风控或平台限制。

## 小红书与抖音接入边界

- 当前以“分享链接／粘贴招聘内容 → AI 匹配 → 高匹配提醒”为可交付能力；
- 抖音全自动搜索需要平台审核对应搜索能力并遵守关键词、时效和业务相关性限制，不能默认扫描全站任意招聘内容；
- 小红书公开开放能力未作为全站招聘内容搜索接口使用，正式自动化前需通过开放平台或商务合作确认权限；
- 获得授权后，可把不同来源做成统一适配器，进入同一套去重、匹配、风险提示和通知流程。
