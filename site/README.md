# Offer Yinli Static Site

This directory is a static frontend. It does not use Next.js, Vinext, Vite, or
server-side rendering for deployment.

Use these settings on the hosting platform:

```text
Framework preset: Other
Root directory: ./site
Install command: npm install
Build command: npm run build
Output directory: dist/client
```

Set `VITE_API_BASE_URL` to the deployed backend URL when the backend is ready.
